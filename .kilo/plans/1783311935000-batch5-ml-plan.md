## Function Signature Categories

### Type A — Matrix X + vector y (regression/classification)
`elasticNet(y, X, {lambda, alpha, ...})`, `huberRegression(y, X, {...})`, `randomForest(X, y, {...})`, `gradientBoosting(X, y, {...})`, `confusionMatrix(actual, predicted, labels)`, `rocAUC(actual, scores)`, `classificationReport(actual, predicted, labels)`, `labelPropagation(X, y, {...})`, `selfTraining(X, y, {...})`, `gradientDescent(X, y, {...})`, `backpropagation(X, y, nHidden, {...})`, `autoencoder(X, {...})`, `variationalAutoencoder(X, {...})`

**UI pattern:** Predictors CheckList → build X matrix; Outcome Sel → y vector. Hyperparameters as Inp fields.

### Type B — Matrix X only (unsupervised)
`tsne(X, {...})`, `isomap(X, {...})`, `lle(X, {...})`, `umapApprox(X, {...})`, `gan(realData, {...})`, `attention(Q, K, V)`, `transformerBlock(X, {...})`

**UI pattern:** Variables CheckList → build X matrix. Hyperparameters as Inp fields.

### Type C — Scalar/vector inputs (no data columns)
`softmax(logits)`, `activate(x, type)`, `softmaxCrossEntropy(logits, targets)`, `adamUpdate(params, grads, mom, vel, {...})`, `xavierInit(nIn, nOut, seed)`, `convolution1D(signal, kernel)`, `conv2D(input, kernel, {...})`, `maxPooling(input, {...})`, `batchNorm(X, {...})`, `dropout(X, rate, {...})`

**UI pattern:** Text/number inputs directly. No column selectors.

### Type D — Model-consuming (needs prior model run)
`partialDependence(model, data, vars, targetVar, {...})`, `accumulatedLE(model, data, vars, targetVar, {...})`, `permutationImportance(model, X, y, {...})`, `shapleyApprox(model, X, baseline, {...})`, `featureInteraction(model, X, i, j)`

**UI pattern:** Re-run a base model internally, then compute the interpretation. Or provide a way to select which model to interpret.

### Type E — Column-based
`localOutlierFactor(data, vars, {...})`, `isolationScore(data, vars, {...})` — take tabular data + column names directly

**UI pattern:** CheckList for columns.

## Implementation Notes

- **elasticNetCV and kFoldCV SKIPPED** — they lack `test:` key and are utilities
- **Name collisions**: Use suffixes to avoid existing tree IDs. `softmax_nn`, `activate_nn`, etc. to avoid conflicts.
- **Model-consuming functions** (partialDependence, etc.): Compute a simple model internally (e.g., `randomForest(X, y, {nTrees: 5})`) then call the interpretation function. The "Run" will compute both the model and the interpretation in one pass.
- **Matrix building pattern**: `useMemo(() => data.filter(r => rowFinite(r, mlXVars)).map(r => mlXVars.map(c => +r[c])), [data, mlXVars])`
- **Single-vector building**: `useMemo(() => data.map(r => +r[mlYVar]).filter(Number.isFinite), [data, mlYVar])`
- **LOWESS special case**: Takes xs/ys vectors (like polynomial regression). Reuse `xy` vectors.
- **Xavier init**: Pure scalar computation, no data needed.
- **Convolution functions**: Take arrays directly from text input fields (comma-separated).
