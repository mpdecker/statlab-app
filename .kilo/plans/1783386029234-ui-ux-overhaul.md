# StatLab UI/UX Overhaul Plan

## Scope
Four interconnected workstreams on the core React frontend (`app/src/`):
1. **Left Navigator** — collapsible categories, sticky headers, scrolling, visual hierarchy

4. **Visualization Quality** — polish all charts in both QuickView and Explore panels

## 7. Risks & Validation

- **localStorage quota**: Favorites + recent + session + panel layout are all small arrays (<1KB total). No risk.
- **Font rendering**: Short text labels (`VLN`, `BOX`, etc.) render in any font. No glyph dependency.
- **Sticky headers**: `position: sticky` is supported in all modern browsers. Must test in `overflow-y: auto` containers.
- **Chart regressions**: Each chart change must be verified visually. Run `npm run test` in `app/` to verify existing chart tests still pass.
- **Breakpoint layout**: The `usePanelLayout` hook (App.jsx line 211) controls panel visibility. Navigator changes must not break the responsive layout.
